# Beveiliging

Meld een kwetsbaarheid niet in een openbaar issue. Gebruik op GitHub **Security → Report a
vulnerability** in deze repository: dan zien alleen de maintainers de melding.

Beschrijf wat je vond, in welke versie of commit, en hoe het na te doen is. Je krijgt binnen vijf
werkdagen antwoord. Een fix komt in een nieuwe versie, met de melding in
[`CHANGELOG.md`](CHANGELOG.md) zodra die openbaar kan.

Alleen de laatste versie krijgt beveiligingsfixes.
