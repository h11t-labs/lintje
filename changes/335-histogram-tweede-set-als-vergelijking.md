### Toegevoegd

- Een histogram tekent een tweede set waarden over dezelfde klassen als trap over de staven: zonder kleur als vergelijking (grijs en gestreept), met een kleur als tweede variabele (doorgetrokken in die kleur). Elke set heeft een eigen knop in de legenda, beide aantallen staan in de tooltip en elke set krijgt een kolom in de CSV (`comparison` op het histogram). (#335)
